Простий калькулятор ціни для відправки посилки українською логістичною компанією Nova Post з Польщі у всі доступні на даний момент країни.

Калькулятор вміє:
-розрахувати об'ємну вагу, 
-розрахувати ціну відправки в залежності від ваги та розмірів посилки, 
-розрахувати суму митних платежів для відправки в Україну
-розрахувати додаткову оплату за "страхування" посилки якщо оціночна вартість перевищує 1000 злотих
-розрахувати вартість разом із пакуванням
-повідомити куди доставка здійснюватиметься партнером UPS

Калькулятор створювався та актуалізується однією людиною, з власної ініціативи, безоплатно у вільний час. 
При створенні та актуалізації калькулятора використовується Штучний Інтелект.
