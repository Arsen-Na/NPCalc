Простий калькулятор ціни для розраховування вартості відправки посилок українською логістичною компанією Nova Post з Польщі у всі доступні на даний момент країни.<br>

Калькулятор вміє:<br>
-розрахувати об'ємну вагу, <br>
-розрахувати ціну відправки в залежності від ваги та розмірів посилки, <br>
-розрахувати суму митних платежів для відправки в Україну<br>
-розрахувати додаткову оплату за "страхування" посилки якщо оціночна вартість перевищує 1000 злотих<br>
-розрахувати вартість разом із пакуванням<br>
-повідомити куди доставка здійснюватиметься партнером UPS<br>

Калькулятор створювався та актуалізується однією людиною, з власної ініціативи, безоплатно у вільний час. <br>
При створенні та актуалізації калькулятора використовується Штучний Інтелект.
